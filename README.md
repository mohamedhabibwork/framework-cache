# @framework/cache

Cache manager, service provider, and drivers backed by @mohamedhabibwork/cachekit.

> **Read-only subtree split** — This package is developed inside the main [**mohamedhabibwork/framework**](https://github.com/mohamedhabibwork/framework/tree/main/packages/cache) monorepo and automatically synced to [`mohamedhabibwork/framework-cache`](https://github.com/mohamedhabibwork/framework-cache). Please open issues and pull requests in the main framework repository.

## Installation

### Inside a Standalone App (via GitHub)

```json
{
  "dependencies": {
    "@framework/cache": "github:mohamedhabibwork/framework-cache"
  }
}
```

```sh
bun install
```

### Creating a New Application

Use the starter application template repository to bootstrap a full application with all framework packages pre-wired:

```sh
gh repo create my-api --template mohamedhabibwork/framework-app --clone
cd my-api
bun install
```
